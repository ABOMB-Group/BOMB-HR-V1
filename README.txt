BOMB HR Enterprise HR Admin V1.38 Unified

V1.38 主管聯絡入口與組織編輯修正：
- 員工人事頁上方新增明顯的「主管電話／LINE 主檔」入口
- 員工查看視窗新增「編輯部門／職位／直屬主管」按鈕
- 員工編輯視窗可直接修改部門、職位、直屬主管、據點與任職狀態
- 預載員工及新建員工皆可保存組織異動，保留修改人與時間
- Employee App 已驗證可讀取主檔 LINE ID、加好友連結與 QR Code

V1.37 主管電話與 LINE 聯絡主檔：
- 後台出勤頁新增主管聯絡主檔，可維護公司電話、私人電話與 LINE 顯示名稱
- 支援 LINE ID、加好友連結及 QR Code 圖片上傳
- 可設定適用部門、班別、代理主管、員工顯示權限及資料驗證狀態
- Employee App 緊急請假改讀取主管聯絡主檔，不再使用固定資料
- 員工可撥號、開啟 LINE、複製 LINE ID或顯示 QR Code，操作時間寫入請假聯絡紀錄

V1.36 員工建檔與待補薪資：
- 一般主管可先建立員工主檔，職位尚無薪資架構時不再阻擋建檔
- 缺少薪資架構的員工標記為待補，財務人事行政與經營管理收到待辦通知
- 有薪資權限者在員工人事卡補齊薪資後，待辦自動完成
- 一般主管預設可調整員工部門、職位、直屬主管與任職狀態
- 薪資預覽不對一般主管顯示，薪資仍由財務人事行政或經營管理維護
- 新增出生年月日，保存於人事主檔並顯示於人事資料卡，供生日禮金及生日假連動

V1.35 出勤扣款與實領連動：
- 後台出勤頁新增企業可調整的打卡、遲到、重大遲到與補卡規則
- Employee App 上班打卡自動計算遲到分鐘及扣款，並寫入薪資人工扣款
- 支援每月分鐘／次數門檻、單次上限及三個月重大遲到人事審查
- 忘記打卡建立主管補簽案件，逾期依企業設定扣除一日薪
- 人事薪資卡新增預估實際領取金額，雇主提撥不從員工實領扣除
- 緊急請假聯絡流程與上述規則在同一完整版本內

V1.34 緊急請假聯絡流程：
- Employee App 新增緊急請假入口、當班主管公司電話、私人電話及 LINE
- 必須先發起電話或 LINE 聯絡，才能確認並送出請假聯絡紀錄
- 後台簽核中心即時收到同一筆緊急請假與聯絡時間
- 主管核准或退回後，Employee App 顯示雙方確認時間軸
- START-DEMO-SERVER.bat 可在同一瀏覽器雙分頁測試後台與 App 共用資料

V1.33 薪資與投保級距規則：
- 未設定的員工依底薪自動選擇大於或等於底薪的最近勞保／健保級距
- 底薪變動時同步更新兩種投保級距與官方試算扣款
- 人工調整並儲存後，以員工個別設定為最高優先，不再套回專員預設值
- 薪資資料改用單一正式儲存鍵，隔離舊版被預設級距污染的資料
