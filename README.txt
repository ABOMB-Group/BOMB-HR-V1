V1.95 排班對象管理：
- 排班頁新增「排班對象」按鈕，可搜尋目前權限範圍內的員工。
- 支援參與排班、不參與排班、指定期間暫停及固定班制。
- 不參與排班可指定生效月份；暫停排班必須設定開始與結束日期。
- 設為不參與或暫停後，員工只從適用月份的班表名單隱藏。
- 員工主檔、登入帳號、薪資、勞健保、假別額度、既有排班資料及歷史班表皆完整保留。
- 恢復「參與排班」後，員工可重新出現在班表。
- 主管僅能調整責任部門，最高權限與人事依原有資料範圍處理。
- 每次變更記錄操作人、員編、身份、責任部門及時間。
