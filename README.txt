BOMB HR Enterprise HR Admin V1.33 Unified

V1.33 薪資與投保級距規則：
- 未設定的員工依底薪自動選擇大於或等於底薪的最近勞保／健保級距
- 底薪變動時同步更新兩種投保級距與官方試算扣款
- 人工調整並儲存後，以員工個別設定為最高優先，不再套回專員預設值
- 薪資資料改用單一正式儲存鍵，隔離舊版被預設級距污染的資料

V1.32 Unified 整併：
- 移除 admin 資源目錄內所有帶 V 版本號的 CSS／JavaScript 檔案
- 介面擴充樣式統一為 admin-unified.css
- 後台互動、保險試算與薪資保存統一為 admin-extensions.js
- 主程式只載入單一整併樣式及單一整併功能檔，避免載入順序及快取互相覆蓋

V1.31 修正：
- 投保級距與薪資扣款／雇主提撥欄位改為真正雙向連動
- 尚未人工設定時，依級距自動回填勞保費、健保費與雇主勞退
- 人工修改過的扣款以人工值優先，不會被自動試算覆蓋
- 四個扣款／提撥欄位與級距在同一次儲存中寫入並讀回驗證

V1.30 修正：
- 儲存時由人事視窗直接綁定員工編號，避免資料寫入其他員工或空白識別
- 所有薪資與勞健保資源加入 V1.30 快取版本，避免瀏覽器載入舊版程式
- 保險／提撥項目改為橫跨整個大型人事視窗

V1.29 修正：
- 修正員工薪資頁勞保／健保級距及人工扣款儲存後重新查看遺失
- 儲存改為單一優先流程，寫入後立即讀回核對
- 儲存完成顯示實際勞保級距、健保級距、操作人與時間
- 放大人事資料視窗至接近全螢幕，薪資頁採雙欄排版以減少捲動

重要修正：
- 修正智慧日期程式未在 APP 啟動時執行的問題
- 原本 initSmartDemo() 被錯放在「送出請假」流程
- 現在 APP 一開啟就立即執行日期、時間與月曆同步
- 加入 DOMContentLoaded 安全啟動
- 加入重複執行防護

開啟 APP 後會立即更新：
- 首頁日期與星期
- 首頁與打卡頁即時時間
- 排班月曆目前月份
- 今日日期標記

- 請假預設日期
