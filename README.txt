- 最高權限可從身份群組直接新增副理／經理、部門主管、財務人事行政、系統管理員、一般員工或自訂身份
- 左側身份清單顯示所有範本、成員數、受保護及可配置狀態
- 部門主管可勾選管理部門，並設定是否包含下層部門、代理部門與跨部門支援員工
- 每個身份均可設定功能層級、敏感資料、人員指派及設定摘要
- 職位與權限身份分開，只有最高權限正式指派後才會取得後台管理能力
